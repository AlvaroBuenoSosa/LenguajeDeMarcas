Cinco cosas que tu web le debe a un lector de pantalla

Bitácora del departamento · 16 de noviembre

Un lector de pantalla no ve tu diseño: lee tu HTML. Si la estructura es buena, la página se entiende aunque no se vea nada.

Títulos en orden

Quien usa un lector de pantalla salta de título en título para hacerse una idea de la página, igual que tú la recorres con la vista. Si te saltas niveles o eliges un h3 porque «se ve más pequeño», ese índice deja de tener sentido. Repasa el tutorial de títulos del W3C.

El aspecto lo decide CSS. La etiqueta se elige por lo que significa.

Listas que son listas

Un menú, una lista de requisitos o un índice son listas, aunque no lleven viñetas. Marcarlas como tales permite al lector anunciar cuántos elementos hay:

  • Menús de navegación.
  • Pasos de un proceso.
  • Grupos de enlaces del pie.

Cómo revisar tu página

  1. Desactiva la hoja de estilos y lee la página de arriba abajo.
  2. Recórrela solo con el tabulador.
  3. Comprueba que todas las imágenes tienen alt.
  4. Pásala por el validador del W3C.

¿Quieres probarlo de verdad? Windows trae Narrador (Ctrl + Windows + Intro) y en Linux tienes Orca.
