Del aula a una aplicación para cuidar mascotas

Este sitio recoge lo que voy aprendiendo en el ciclo de Desarrollo de Aplicaciones Multiplataforma (DAM) y lo aplico a una idea: Huellas, una aplicación para organizar los cuidados de una mascota.

Aprender haciendo

Un proyecto de software empieza por entender una necesidad, organizar la información y construir una solución que sea fácil de usar.

En clase practicamos estos pasos con programación, bases de datos y lenguajes de marcas.

Consulta cómo se aplica ese proceso al proyecto Huellas.

Plan de aprendizaje

Estas son algunas áreas del ciclo y cómo ayudan a construir el proyecto.

Áreas de aprendizaje y su aplicación en Huellas
Área Qué se aprende Aplicación en el proyecto
Programación Diseño de algoritmos y escritura de código. Crear funciones para registrar y consultar cuidados.
Bases de datos Organización y consulta de información. Guardar mascotas, citas y recordatorios.
Lenguajes de marcas Estructuración semántica de documentos web. Presentar la información de forma clara y accesible.

Primeros pasos del proyecto

De una necesidad a una solución

Huellas parte de una situación cotidiana: recordar las tareas importantes para el bienestar de una mascota.

  • Anotar los datos básicos de la mascota.
  • Registrar citas y cuidados periódicos.
  • Consultar la información cuando haga falta.
